\# CashBook Nepal



CashBook Nepal is a Nepal-focused Android cashbook and bookkeeping application built with Kotlin, Jetpack Compose, Room and MVVM.



The project is designed for personal finance, small businesses, offices and project/site expense management, with first-class support for Nepal's Bikram Sambat (BS) calendar.



\## Current Features



\- Cash In and Cash Out transactions

\- Add, edit and delete transactions

\- Persistent Room database

\- Dashboard with:

&#x20; - Current balance

&#x20; - Total Cash In

&#x20; - Total Cash Out

&#x20; - Recent transactions

\- Real Bikram Sambat (BS) and Gregorian (AD) date system

\- BS/AD preference saved in Settings

\- Transaction dates stored as canonical epoch milliseconds

\- Category management

\- Custom categories

\- Payment methods such as Cash, eSewa, Khalti and others

\- Custom payment methods

\- Contact/party selection

\- Custom contacts

\- Multiple Cashbooks

\- Separate balance and transactions for each Cashbook

\- Cashbook switcher on the Dashboard
